# MossHub v5.4

Удобный лаунчер и экосистема для управления проектами и игровыми сообществами, разработанная командной **MossTeam**.

## Особенности
* Быстрый запуск и управление игровыми файлами.
* Современный интуитивный интерфейс.
* Удобный официальный установщик (`MossHub_Setup.exe`) с автоматическим созданием ярлыков на рабочем столе и в меню «Пуск».

## Установка
1. Скачайте последний релиз **`MossHub_Setup.exe`** из раздела [Releases](../../releases).
2. Запустите файл и следуйте инструкциям на экране.
